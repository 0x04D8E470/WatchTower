# WatchTower – Telegram Bot для мониторинга и тестирования API

Telegram-бот, который объединяет автоматический мониторинг доступности веб-сервисов и ручной HTTP-клиент (как Postman) прямо в мессенджере.

## Возможности

### Мониторинг

- Добавление URL для мониторинга с заданным интервалом и ожидаемым статусом
- Автоматические проверки с уведомлениями при падении/восстановлении сервиса
- SSL-мониторинг: предупреждения об истечении сертификата
- Просмотр статуса всех мониторингов (`/status`)
- Управление: пауза, возобновление, удаление (`/pause`, `/resume`, `/delete`)

### Ручной HTTP-клиент

- Быстрые команды: `/get`, `/post`
- Пошаговый мастер запросов: `/request` (выбор метода, заголовков, тела)
- Сохранение шаблонов запросов и запуск по имени (`/templates`, `/run`)
- История последних запросов (`/history`)
- Поддержка всех основных HTTP-методов (GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS)
- Автоматическое определение типа тела (JSON, raw)
- Защита от бинарных ответов и превышения лимитов Telegram

### Безопасность

- Защита от SSRF: валидация URL, проверка на локальные/приватные адреса
- Экранирование HTML во всех выводимых сообщениях
- Ограничение размера ответа (soft limit)

### Архитектура

- Асинхронный стек: aiogram, SQLAlchemy async, httpx
- Паттерн Dependency Injection (через middleware)
- Централизованное управление транзакциями БД (Unit of Work)
- Слой сервисов, изолированный от Telegram и БД
- Фоновый планировщик (APScheduler) с адаптивной выборкой мониторов
- Безопасный HTTP-клиент с таймаутами, ретраями и лимитом редиректов
- Юнит-тесты (pytest + pytest-asyncio + pytest-mock)

## Технологии

- Python 3.11, aiogram 3, SQLAlchemy 2 (async), Alembic
- PostgreSQL, Redis, APScheduler, httpx
- Docker Compose, structlog

## Быстрый старт

1. Клонируйте репозиторий
2. Скопируйте `.env.example` → `.env` и впишите токен бота
3. `docker-compose up -d`
4. Напишите боту `/start`

## Структура проекта

- `app/bot/` – обработчики Telegram (handlers, middlewares, states)
- `app/services/` – бизнес-логика (мониторинг, ручные запросы, уведомления)
- `app/db/` – модели SQLAlchemy и репозитории
- `app/scheduler/` – фоновые проверки мониторов
- `app/core/` – конфигурация, логирование
- `app/utils/` – вспомогательные модули (HTTP-клиент, форматирование)
